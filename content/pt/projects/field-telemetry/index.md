**Situação do projeto:** Projeto experimental — arquitetura em desenvolvimento.

Desenvolvimento de uma arquitetura compacta de telemetria com **ESP32 e rádios LoRa** para instrumentação e monitoramento remoto. A proposta enfatiza comunicação de longo alcance, baixo custo operacional e integração com sensores para aplicações ambientais ou hidrológicas.

O projeto funciona como plataforma para testar aquisição de dados e comunicação robustas sob as restrições reais de campo.
